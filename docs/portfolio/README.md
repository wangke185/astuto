# Public Planning Portfolio

These documents are public hypothetical exercises or bounded case-study artifacts. They are intended to demonstrate planning method, technical reasoning, scope control, ticket quality, acceptance criteria, technical communication, and evidence-based delivery.

They do not claim confidential client work or affiliation with the organizations whose public problem domains may have inspired an exercise.

## Product planning

- [Multi-Tenant Club Booking Waitlist](./multitenant-club-booking-waitlist-planning-sample.md) — problem definition, policy model, user flow, state model, API sketch, edge cases, implementation tickets, acceptance criteria, rollout, metrics, and open decisions for a hypothetical sports-club SaaS.

## Technical writing and implementation

- [Build a Secure Webhook Receiver in Next.js with TypeScript](./secure-nextjs-webhook-receiver.md) — an App Router tutorial covering raw-body signature verification, replay protection, payload limits, idempotency, durable queues, status-code policy, tests, and production checks.
- [Runnable secure Next.js webhook receiver](../../examples/secure-nextjs-webhook-receiver/README.md) — a compact implementation with HMAC verification, event validation, idempotency and queue boundaries, focused tests, type checking, and a production-build CI workflow.

## Technical rescue
