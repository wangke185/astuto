### One-line outcome

### Description

Messy CSV and spreadsheet exports often contain duplicate rows, inconsistent headers, blank records, stray whitespace, mixed missing-value markers, broken column mappings, and fields that do not follow the rules required by a CRM, reporting workflow, or database import.

I will clean the data against written rules and return a reproducible result rather than making silent guesses.

Typical work includes:

- exact deduplication by full row or agreed key columns;
- text trimming and whitespace normalization;
- missing-value normalization;
- column rename / mapping to a target schema;
- explicit row filtering;
- split / merge transformations;
- required-field validation;
- exception lists for rows that cannot be changed safely;
- before / after row counts and a short change log;
- reusable Python or JavaScript cleanup scripts on Standard / Advanced work.

A public browser-only proof is available in the GitHub repository and demonstrates deterministic parsing, cleaning, profiling, CSV export, and quality reporting without uploading source data.

I do not guess ambiguous dates, merge fuzzy identities, invent missing values, or alter IDs unless the rule is explicitly agreed first.

### FAQ

**Will you upload my data to a third-party AI service?**

Not by default. The public proof runs locally in the browser. For paid work, the processing method is agreed before work begins, and no production credentials are requested.

**Can you clean Excel `.xlsx` files?**

Yes when the scope is agreed, but the public proof currently demonstrates CSV / TSV processing. If the workbook contains formulas, macros, merged cells, or presentation formatting that must be preserved, that is scoped separately before purchase.

**Can you merge near-duplicate names such as “Acme Ltd” and “ACME Limited”?**

Only using an agreed rule or review sample. Fuzzy matching is not applied silently.

**Will you fill missing data automatically?**

No. Missing values are not invented. I can flag them, normalize markers, or apply a written rule supplied by the client.
